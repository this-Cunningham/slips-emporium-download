# Slip's Emporium for WoW Forever

Downloads only. Get the zip from the **[latest release](../../releases/latest)**.

**Slip's Emporium** shows which Craftsman's Writs and Waylaid Crates are worth filling: live auction house cost against reputation and Merchant's Favor, where to hand each one in, a cheapest-route plan to your next standing, and buttons to buy what you need. Type `/slips` in game.

**ForeverRXP** adds RestedXP guides and navigation for WoW Forever. With it (and RestedXP Guides) Slip's Emporium plans routes with real travel times and can send your delivery route to RestedXP's arrow.

## Install

1. Close the game.
2. Download `SlipsEmporium-and-ForeverRXP.zip` from the latest release.
3. Unzip it into `World of Warcraft\_forever_\Interface\AddOns`, so you have `AddOns\SlipsEmporium` and `AddOns\ForeverRXP`.
4. For ForeverRXP, also install **RestedXP Guides** from CurseForge. Slip's Emporium works without it.
